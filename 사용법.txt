보수작업 승인(신청)서 작성 프로그램
=====================================

[실행]
  1. 압축 파일을 마우스 오른쪽 클릭 → [모두 압축 풀기]로 먼저 풉니다 (압축 안에서 바로 실행하면 안 켜짐)
  2. 풀린 폴더의 보수작업신청서.vbs 더블클릭
  3. 오류가 나면 오류 창이 뜨고 %APPDATA%\BosuForm\error.log 에 기록됩니다

[자동 업데이트]
  - 프로그램을 켤 때마다 GitHub(github.com/ghj3815/bosu-form)에 새 버전이 있는지 확인하고,
    있으면 자동으로 받아서 업데이트한 뒤 "업데이트 내용" 안내창을 띄웁니다
  - 인터넷이 안 되면 확인을 건너뛰고 지금 버전으로 실행합니다
  - 현재 버전은 프로그램 창 제목에 표시됩니다
  - (관리자) 프로그램을 수정한 뒤 "업데이트배포.bat"을 실행 → 업데이트 내용 입력 → GitHub에 올라감

[처음 설정] - 처음 실행하면 설정 창이 뜹니다
  1. 서식 파일 : 같은 폴더의 "보수작업신청서_서식.xlsx" (자동 지정됨, 다른 서식으로 바꿀 수 있음)
  2. 수출입자 DB / 신청인 DB : 공유폴더에 둔 csv 파일 2개 (없으면 각각 [새로 만들기]로 생성,
     이 폴더의 수출입자DB.csv, 신청인DB.csv를 공유폴더로 복사해서 써도 됨)
     ※ 이전 버전의 업체 DB는 수출입자 DB로 그대로 이어집니다
  3. 저장 폴더 : PDF가 저장될 폴더 (기본 바탕화면)
  설정은 PC마다 저장됩니다 (%APPDATA%\BosuForm\settings.json)

[사용 순서]
  1. 수출(입)자 상호(수출입자 DB) / 신청인 상호(신청인 DB) 선택 → 성명, 주소 자동 입력
     - DB에 없는 상호를 쓰거나 성명/주소를 고치면 PDF 생성 때 DB에 추가/수정할지 물어봅니다
  2. B/L번호 입력 → [UNI-PASS 조회] (또는 Enter)
     - UNI-PASS Open API로 바로 조회합니다 (브라우저 창이 열리지 않음)
     - 처음 한 번 [설정] 창의 "UNI-PASS API 키" 칸에 인증키를 입력해야 합니다 (PC마다 저장됨)
     - 자동(H→M): House B/L로 먼저, 없으면 Master B/L로 조회. 올해 없으면 작년도 조회
     - 입항일자, 선(기)명, 장치장소, 반입신고번호, 포장, 품명이 채워집니다
     - 장치장소는 "장치장명(장치장부호 8자리)" 형식
     - 반입신고가 여러 번이면 가장 최근 반입신고 기준
     - B/L 하나에 화물관리번호가 여러 개면 [화물관리번호 선택] 창이 뜹니다
       · 줄을 클릭하면 그 화물의 선명/포장·중량/장치장소/품명을 바로 불러와 보여줍니다
       · 해당 건을 더블클릭(또는 선택 후 [선택])하면 그 화물관리번호로 채워집니다
     - [화면에서 가져오기]는 예비용: UNI-PASS 웹 화면(Edge)에 열어 둔 상세 화면을 그대로 읽어옵니다
  3. 작업목적, 작업방법, 규격/수량/가격, 사용재료 입력
     - 신청일자(기본 오늘)가 서식 하단 연월일에 들어가고, 작업기간은 신청일자 ~ +7일로 자동 입력 (직접 수정 가능)
     (작업목적/방법은 입력했던 내용이 목록에 남습니다)
  4. [미리보기]로 서식에 들어간 모습을 확인 (저장 안 됨, 창에서 바로 [PDF 생성] 가능)
  5. [PDF 생성] → "BL번호_보수작업신청서.pdf" 저장

[명판직인]
  - [신청인 DB] → 업체 행 선택 → [선택한 업체에 명판직인 지정] → 이미지 선택 (선택하는 즉시 저장됨)
    · 직인파일 칸을 더블클릭하거나, 이미지 파일을 업체 줄 위로 끌어다 놓아도 됩니다
  - ※ csv 파일을 엑셀로 열어 칸에 그림을 붙여 넣으면 저장할 때 그림이 지워집니다 (csv는 글자만 저장됨)
    엑셀로 직접 적을 때는 이미지 파일 이름만 적고(예: 회사명.png), 그 파일을 신청인 DB 폴더의 "직인" 폴더에 넣으세요
  - 이미지는 신청인 DB 폴더의 "직인" 폴더로 복사되어 팀원 PC에서도 같이 씁니다
  - 직인이 등록된 신청인을 고르면 신청인 칸 제목에 "명판직인 등록됨"이 표시되고,
    PDF 생성 시 신청인 서명란에 이미지가 자동으로 들어갑니다 (이때 "상호 성명 (인)" 글자는 넣지 않음)
  - 배경이 투명한 PNG를 권장합니다

[참고]
  - 엑셀이 설치되어 있어야 PDF를 만들 수 있습니다
  - 모든 칸은 조회 후에도 직접 고칠 수 있습니다
  - 업체는 [수출입자 DB] / [신청인 DB]에서 추가/수정/삭제 (엑셀로 직접 고칠 때는 "CSV UTF-8" 형식으로 저장)
  - 조회용 Edge는 일반 Edge와 별도 프로필(%APPDATA%\BosuForm\browser)을 씁니다
